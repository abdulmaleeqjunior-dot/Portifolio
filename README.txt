# Abdulmaleeq Portfolio — First Version

Files:
- index.html
- style.css
- script.js

How to run:
1. Put all three files in the same folder.
2. Open index.html in a browser, or use VS Code + Live Server.
3. Replace the demo project names/content with your actual work.
4. Add your real WhatsApp number and email in the contact section when ready.

Important:
- The contact form is currently demo-only; it does not send email.
- Google Fonts is loaded from fonts.googleapis.com when online.
- Demo projects are clearly identified as concepts.
